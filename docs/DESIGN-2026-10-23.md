# CricScore — Frontend Design Elevation, 2026-10-23

Guided by the skills.sh **web-design-guidelines** skill (Vercel Web
Interface Guidelines, fetched fresh from
`vercel-labs/web-interface-guidelines`) and the Design lens of
`ANALYSIS-2026-10-23.md` (verdict B; F-14 focus/landmarks already fixed
in `FIXES-2026-10-23.md` and not redone). Scope: the React app in
`user/` only. The dark emerald/lime identity is unchanged — this pass
systematises and polishes it. **No behaviour changed**: every route,
flow and API call works exactly as before; no new features, no data
touched.

## 1. Design-system layer (`src/index.css`, `index.html`)

- **WCAG AA contrast tokens.** `--color-secondary` (the meta-text tone
  used in 24 files) failed AA at small sizes in both themes. Dark:
  `#66788f` → `#8498b3` (~3.4:1 → ~6:1 on card). Light: `#8494ab` →
  `#5d7089` (~3.0:1 → ~4.9:1 on white). Every meta label, date and
  caption in the app lifts at once.
- **`color-scheme: light/dark`** on `:root`/`.dark` (guideline: dark
  mode & theming) — native scrollbars and form controls now match the
  active theme. Matching `theme-color` meta split per scheme in
  `index.html`.
- **Touch hygiene (guideline: Touch & Interaction).**
  `touch-action: manipulation` on all interactive elements (kills the
  double-tap zoom delay — matters for rapid ball-pad scoring) and an
  intentional `-webkit-tap-highlight-color: transparent`.
- **`prefers-reduced-motion` support** (guideline: Animation). A global
  reduce block collapses the ambient loops — hero drift, skeleton
  shimmer, live-dot ping, score pop, Manhattan grow — to a still frame
  and makes transitions effectively instant. The live dot and spinner
  remain visible, just static.
- **Typography details:** `text-wrap: balance` on `h1–h3`;
  `scroll-margin-top: 5rem` on anchored ids so targets clear the sticky
  navbar.
- **New shared component classes** (one source for patterns that were
  copy-pasted with drift):
  - `.btn-primary` — emerald→lime gradient pill CTA (hover lift on
    hover-capable pointers only, explicit `transform, box-shadow`
    transition).
  - `.btn-icon` — 44×44 round icon button (navbar toggle/menu were
    ~35px, under the comfortable touch target).
  - `.count-pill` — the section count chip (was re-declared in Home,
    Matches, FeaturedMatch).
  - `.tab-bar` / `.tab-item` / `.tab-item-active` — segmented control
    (was re-declared in Matches, TournamentInfo, Match).
  - `.live-badge` — the rose LIVE label.
  - `.card-link` — clickable-card hover lift, transform/box-shadow
    only, hover-media gated.
  - `.empty-panel` — dashed inset panel for empty states.
  - `.data-table` (+ `.num`) — broadcast-style data table: 11px
    uppercase secondary-tone headers, soft row dividers, row hover,
    tabular numbers throughout.
  - `.row-hover` — row highlight for hand-built tables (scorecard).

## 2. Shared components

- **NavBar** — theme/menu buttons → `.btn-icon` (44px targets), both
  "Start Scoring" CTAs → `.btn-primary`, nav links get 40px height and
  `transition-colors` (was `transition-all`).
- **States** — Retry → `.btn-primary`; `EmptyBox` is now a real empty
  state (dashed `.empty-panel` + icon); spinner uses `emerald-500`
  instead of an arbitrary hex.
- **Match cards → real links (guideline: `<a>`/`<Link>` for
  navigation).** `ScoreSummaryCard`, `Recent`, `Upcoming`,
  `TournamentsCard` and the hero `FeaturedMatch` were
  `div[role=button]` + `useNavigate`; they are now `<Link>`s with
  `.card-link` — middle-click / Cmd-click / open-in-new-tab work, and
  the hand-rolled key handlers are gone (native anchor semantics).
  Tournament cards still pass router `state` exactly as before.
- **PointsTable** — rebuilt on `.data-table` with `scope="col"`.
- **TournamentStats** (Orange/Purple Cap leaderboards) — both tables
  rebuilt on `.data-table`; rank-1 highlight rows kept.
- **Scorecard** — numeric columns (R/B/4s/6s/SR, O/M/R/W/Econ/NB/WD)
  right-aligned with consistent header padding so figures line up
  down the column; batting/bowling rows get `.row-hover`; the stray
  trailing `&nbsp;` spacer is gone.
- **LiveDot** — marked `aria-hidden` (decorative; the LIVE text beside
  it carries the meaning).
- **LiveTicker** — chips get a taller tap target (`py-2`).

## 3. Pages

- **Home** — count pills → `.count-pill`; section empty states →
  `EmptyBox` panels (were bare paragraphs); "View All" hover colour
  tokenised, `transition-all` → `transition-colors`.
- **Matches** — type tabs → `.tab-bar`/`.tab-item`; count →
  `.count-pill`; empty state → `EmptyBox`.
- **Tournaments** — page header rebuilt to the Matches pattern (accent
  bar, condensed uppercase **`<h1>`** — the page previously had no
  heading element at all) + count pill + `EmptyBox`.
- **TournamentInfo** — tabs → shared tab classes (roles/aria kept);
  banner dates via the Intl formatter; fixtures empty → `EmptyBox`.
- **Match** — tab buttons → `.tab-item`; innings pills
  `transition-all` → `transition-colors`; added an sr-only `<h1>`
  ("Team A vs Team B — live score & scorecard") — the page's visual
  header is a scoreboard, so the document outline now starts correctly
  without changing the layout.
- **Login** — now consumes the shared `formStyles` (`inputCls`,
  `labelCls`, `primaryBtnCls`) instead of a private duplicate of the
  input classes; title is an `<h1>`; accent hexes tokenised to
  `emerald-500`.
- **Dates everywhere (guideline: Locale & i18n)** — `fmtDate` in
  `lib/formStyles.js` now uses `Intl.DateTimeFormat` ("Mon 20 Oct
  2026"), and the eight remaining direct `toDateString()` call sites
  (Recent, Upcoming, ScheduleCard, MatchDetails, TournamentInfo,
  ScorerMatches, ManageTournament) route through it. One format,
  locale-aware, app-wide.

## 4. Organizer / scorer consistency pass

- **StickyBar** — bottom inset now respects the phone safe area:
  `pb-[max(0.75rem,env(safe-area-inset-bottom))]` (guideline: Safe
  Areas); undo button transition made explicit.
- **BallPad / PickerSheet / ScorerConsole** — `transition-all` →
  explicit `transition-transform` / `transition-colors` /
  property lists.
- **ScorerMatches cards, Features, HeroSection, TournamentSpotlight**
  — same `transition-all` purge (9 files total; zero remain in the
  app). Organizer pages also inherit the AA contrast lift and the
  shared form styles unchanged.

## 5. Deliberately NOT applied (and why)

- **URL-synced tab state** (guideline: deep-link stateful UI). Match /
  TournamentInfo tabs stay in `useState` — syncing them to the URL
  changes navigation behaviour, which this pass was forbidden from
  touching.
- **List virtualisation** — viewer lists are capped at 4 cards per
  section (Home) and fixture-length lists elsewhere; nothing renders
  the >50-row lists the rule targets.
- **Font preloads** — fonts already load via Google Fonts with
  `display=swap` + preconnect; hand-preloading hashed woff2 URLs is
  brittle against Google rotating them.
- **`@theme` colour migration** — the codebase's hand-written semantic
  classes (`bg-secondary` = background tone vs `text-secondary` =
  text tone) deliberately overload one name for two tones; forcing
  them into Tailwind theme colours would change rendered colours in
  places that can't be visually verified on this VM.
- **Scorer console decoration** — left functionally untouched beyond
  transitions/safe-area: it is a working tool used one-handed at
  grounds; clarity over ornament, per the brief.
- **Light-mode `theme-color` for in-app theme toggle users** — the
  meta follows the OS scheme; the in-app toggle is class-based and
  can't be expressed in static meta tags.
